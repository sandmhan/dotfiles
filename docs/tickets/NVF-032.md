# NVF-032: Replace NVF CodeCompanion workflow with Avante.nvim

## Summary

Replace the NVF CodeCompanion-based AI companion and Neovim Pi bridge provider with a gated Avante.nvim workflow while preserving standalone Pi, Codex, and Claude Home Manager tooling.

## Purpose

Align the NVF in-editor AI workflow with the preferred Avante.nvim provider path and remove Pi from Neovim-specific bridge integration without removing the existing non-Neovim AI command-line tooling.

## Context

NVF-031 adopted CodeCompanion as the initial mature in-editor AI workflow after evaluating Avante.nvim and related options. Follow-up research and planning now direct the implementation toward Avante.nvim through `vim.assistant.avante-nvim.enable`, with OpenAI-compatible provider configuration and hardened context/keymap behavior. The change must remove CodeCompanion from NVF, remove Pi only from the Neovim bridge provider list, keep Claude and Codex bridge behavior, and leave standalone Pi/Codex/Claude Home Manager modules intact.

## Acceptance criteria

- [x] `home/modules/nvf/default.nix` imports a new Avante module instead of the CodeCompanion module, and CodeCompanion NVF wiring is removed.
- [x] A gated `home/modules/nvf/ai-avante.nix` enables `vim.assistant.avante-nvim` behind a new `myHome.features.enableNvfAiAvante` option.
- [x] Avante is configured for OpenAI-compatible provider usage with environment-driven API key, base URL, and model defaults, and no credentials are committed.
- [x] Avante defaults are hardened so automatic keymaps, suggestions, automatic diff application, hints, and broad editor-context/tool behaviors are not enabled by default.
- [x] Explicit leader-a Avante keymaps replace the CodeCompanion prompt workflow, including selected-code edit, review, and test actions without duplicated visual ranges.
- [x] `home/options.nix` and affected Home Manager profiles use `enableNvfAiAvante` instead of `enableNvfAiCompanion`.
- [x] The Neovim AI bridge removes only the Pi provider while preserving guarded Claude and Codex bridge commands, keymaps, confirmation, and redaction behavior.
- [x] Standalone `home/modules/ai-pi.nix`, `home/modules/ai-codex.nix`, `home/modules/ai-claude.nix`, and non-Neovim Pi/shared-skill auto-enable behavior remain intact.
- [x] `README.md`, `docs/neovim-ide.md`, Phase 5/7 validation scripts, and evidence documentation are updated to describe Avante, the Claude/Codex bridge boundary, provider setup, privacy expectations, and validation commands.
- [x] Validation evidence covers NVF phase checks, formatting/diff checks, affected Home Manager dry-runs, and a runtime Neovim smoke check for Avante and the remaining bridge commands, or documents any deferred runtime checks with affected profiles.
